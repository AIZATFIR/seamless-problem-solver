# Terra — Seamless Problem Solver

A minimalist web application for problem reflection and stress relief rooted in Stoic philosophy.

Live Demo: [seamless-problem-solver.vercel.app](https://seamless-problem-solver.vercel.app)

## Features

- **Interactive Problem Solver**: Step-by-step reflection flow based on the Stoic trichotomy of control.
- **4-7-8 Breathing Guide**: Guided relaxation timer with visual cues.
- **Reflection Journal**: Local storage journal for tracking thoughts and action steps.
- **Web Audio Ambient Sounds**: Procedural background sound generator for focus and calm.
- **Bilingual**: Toggle between Indonesian and English.
- **Theme Switcher**: Dark and light mode support.

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript (ES Modules)
- Vite
- Vercel (Hosting)

## Getting Started

### Prerequisites

Node.js (v18 or higher) and npm installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AIZATFIR/seamless-problem-solver.git
   cd seamless-problem-solver
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.

## Build for Production

To generate a static build:

```bash
npm run build
```

The output will be in the `dist` directory.
