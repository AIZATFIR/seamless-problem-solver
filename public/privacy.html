Kebijakan Privasi

Terakhir diperbarui: 1 Oktober 2026 · Efektif berlaku

Di Terra Flow, kami menghormati privasi dan kedaulatan data Anda. Dokumen ini menjelaskan bagaimana data Anda dikelola saat menggunakan layanan web kami di https://seamless-problem-solver.vercel.app/.

1. Arsitektur Local-First Storage

Diagram flowchart yang Anda buat, riwayat langkah, dan catatan jurnal ketenangan disimpan secara lokal di perangkat Anda menggunakan teknologi localStorage peramban. Kami tidak mentransmisikan isi catatan atau diagram Anda ke basis data eksternal.

2. Sub-Prosesor & Layanan Pihak Ketiga

Untuk menyajikan aplikasi web secara andal, kami menggunakan infrastruktur berikut:

  • Vercel Inc. (USA): Penyedia hosting edge network dan penyampaian aset statis (HTML/JS/CSS).
  • Google LLC (Fonts): Penyedia tipografi web via Google Fonts CDN.

3. Bebas Pelacak & Iklan

Kami tidak menggunakan pelacak iklan pihak ketiga, tidak menjual profil perilaku pengguna, dan tidak menyisipkan skrip analitik yang mengumpulkan identitas pribadi (PII).

4. Hak Anda

Anda berhak menghapus seluruh riwayat kapan saja dengan membersihkan cache peramban atau mengunduh cadangan alur dalam format JSON standar.
